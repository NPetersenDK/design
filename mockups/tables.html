F. Standard table, mode 1: row expands

Now in design.css: th.sort, tr.clickable, td.chev, .open, .rowdetail

A: the whole row is clickable. D: clicking a row opens its detail row, and the row stays highlighted while open. B: headers and rows are not Tab stops, so Tab only visits real links and buttons (Name, Manage). C: Font Awesome arrows and aria-sort. Inactive columns show a faint so you can see they sort, and the column does not change width when the active one moves. The small chevron in the first column only shows state; it is not a button. Clicking the Name link or Manage does not toggle the row.
